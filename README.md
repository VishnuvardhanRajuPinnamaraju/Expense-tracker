# Expense-tracker
using  c++
### Smart Budget Alert Feature

I added a **Smart Budget Alert** feature to the expense tracker to help users control their spending and avoid exceeding their planned budget. The main problem with a basic expense tracker is that it only records expenses; users have to manually check their total spending and may not realize that they are close to exceeding their budget.

The feature allows the user to set a **monthly budget**. Whenever a new expense is added, the program calculates the total amount spent and compares it with the budget. Based on the remaining amount, it provides a simple alert to the user. For example, it can warn the user when they have used a large portion of their budget and give a stronger warning when the budget is exceeded.

I implemented this using basic **C++ concepts such as variables, functions, vectors, conditional statements, and switch-case**. The expense data is stored and updated whenever a new expense is entered. The budget-checking function then calculates the remaining balance and displays the appropriate message.

This makes the application more useful because it changes the expense tracker from a simple **record-keeping system into a basic spending-management tool**.
